국내주식 단타 레이더 - Yahoo Finance 버전

구성
- index.html
- manifest.webmanifest
- sw.js

사용
1. GitHub 저장소에 압축을 풀어 파일 3개와 README를 업로드합니다.
2. 저장소 Settings > Pages에서 배포를 켭니다.
3. 생성된 GitHub Pages 주소를 Chrome으로 엽니다.
4. 감시 시작을 누릅니다. 홈 화면에 추가하면 앱처럼 실행할 수 있습니다.

중요 제한
- 국내 주식 실시간 시세나 10초 갱신을 보장하지 않습니다.
- Yahoo Finance와 중계 서비스의 정책/가용성에 따라 중단될 수 있습니다.
- 화면을 벗어나면 감시를 중지합니다. 백그라운드/푸시 감시는 없습니다.
- 신호는 직전 조회가 대비 단순 변화 표시이며 투자 조언 또는 자동주문이 아닙니다.
